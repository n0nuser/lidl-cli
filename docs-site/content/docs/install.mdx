## go install

```bash
go install github.com/n0nuser/lidl-cli/cmd/lidl@latest
lidl --version
```

## Release binaries

Each [release](https://github.com/n0nuser/lidl-cli/releases) has archives for Linux, macOS and Windows on
amd64 and arm64, plus `checksums.txt` with a GitHub provenance attestation.

```bash
gh release download --repo n0nuser/lidl-cli --pattern 'lidl_*_linux_amd64.tar.gz' --pattern checksums.txt
sha256sum --ignore-missing -c checksums.txt
gh attestation verify checksums.txt --repo n0nuser/lidl-cli
tar xzf lidl_*_linux_amd64.tar.gz lidl && mv lidl ~/.local/bin/
```

## From source

```bash
git clone https://github.com/n0nuser/lidl-cli && cd lidl-cli
make build   # bin/lidl
```

## Check it

```bash
lidl doctor --format pretty
```

## Updates

`lidl update` replaces a release binary with the latest release after checking its checksum. `--check` only
reports. Interactive commands look for a release at most once a day and ask first; `LIDL_NO_UPDATE_CHECK=1`
turns that off. Builds from source are left alone.

## Files

| what | where |
|---|---|
| config | `~/.config/lidl-cli/config.toml` |
| watches and events | `~/.local/share/lidl-cli/state.db` |
| update stamp | `~/.cache/lidl-cli/` |
| timer log | `~/.local/state/lidl-cli/lidl-watch.log` |

The XDG variables move them; `lidl config path` prints them.
