## `lidl config`

Read and write config.toml

Read and write config.toml. Keys are dotted paths.

```bash
lidl config path
lidl config set watch.interval 1h
lidl config set sinks.phone.type ntfy
lidl config set sinks.script.command '["/home/me/bin/on-event", "--quiet"]'
lidl config get sinks.phone
```

### `lidl config get`

Print one key

```bash
lidl config get KEY
```

### `lidl config list`

Print the whole config

```bash
lidl config list
```

### `lidl config path`

Print where the CLI keeps its files

```bash
lidl config path
```

### `lidl config set`

Set one key; exec commands take a TOML string array

```bash
lidl config set KEY VALUE
```
