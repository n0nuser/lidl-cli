## `lidl sink`

Notification targets for watch events, from config.toml

Sinks deliver watch events somewhere besides stdout: an ntfy topic, a JSON
webhook (raw event, or a discord/slack text message), or a local program that
gets the event JSON on stdin. Define them in config.toml.

```bash
lidl config set sinks.phone.type ntfy
lidl config set sinks.phone.url https://ntfy.sh
lidl config set sinks.phone.topic my-lidl-alerts
lidl sink test phone
```

### `lidl sink list`

List sinks and what is wrong with them

```bash
lidl sink list
```

### `lidl sink test`

Send a made-up event to a sink

```bash
lidl sink test NAME
```
