## `lidl search`

Search products with the site's filters

```bash
lidl search [keywords...] [flags]
```

Search products using the filters the site offers: brand, price range,
rating, availability, sort order and any facet from `lidl search filters`.

Keywords are optional when --category, --brand or --filter narrows the
search. Lidl sells limited-time offers, so the list changes: use --sort
newest or discount to see what is new or marked down, and read price.old_price
and price.end for the promotion.

```bash
lidl search atornillador --format pretty
lidl search atornillador --max-price 40 --sort price_asc --in-stock
lidl search --category "Bricolaje y jardín" --sort discount --limit 10
lidl search taladro --brand parkside --min-rating 4 --pages 2 --format jsonl
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--brand` | stringArray | - | brand, repeatable (the site's Marca facet; case does not matter) |
| `--category` | string | - | the site's category facet value, for example "Bricolaje y jardín" (see `lidl search filters`) |
| `--filter` | stringArray | - | facet CODE=VALUE, repeatable (see `lidl search filters`) |
| `--in-stock` | bool | `false` | only products available online |
| `--limit` | int | `0` | stop after this many products (0: whole pages) |
| `--max-price` | float64 | `0` | maximum price in EUR |
| `--min-price` | float64 | `0` | minimum price in EUR |
| `--min-rating` | float64 | `0` | minimum average rating, 1 to 5 |
| `--page` | int | `1` | result page to start at (48 products per page) |
| `--pages` | int | `1` | how many pages to fetch |
| `--sort` | string | `relevance` | order: relevance, price_asc, price_desc, newest, rating, bestselling, discount |

### `lidl search filters`

List the filters the site offers for a search

```bash
lidl search filters [keywords...] [flags]
```

List the facets the site offers for a search, with the values and how many
products each has. Pass CODE=VALUE to --filter.

```bash
lidl search filters atornillador --format pretty
lidl search filters --category "Bricolaje y jardín"
```

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--brand` | stringArray | - | brand, repeatable (the site's Marca facet; case does not matter) |
| `--category` | string | - | the site's category facet value, for example "Bricolaje y jardín" (see `lidl search filters`) |
| `--filter` | stringArray | - | facet CODE=VALUE, repeatable (see `lidl search filters`) |
| `--in-stock` | bool | `false` | only products available online |
| `--max-price` | float64 | `0` | maximum price in EUR |
| `--min-price` | float64 | `0` | minimum price in EUR |
| `--min-rating` | float64 | `0` | minimum average rating, 1 to 5 |
| `--sort` | string | `relevance` | order: relevance, price_asc, price_desc, newest, rating, bestselling, discount |
